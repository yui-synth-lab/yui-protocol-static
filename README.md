# YUI Protocol Static Site

YUI Protocolの静的デモンストレーションサイトです。GitHub Pagesで公開されています。

## 概要

このプロジェクトは、YUI Protocolシステムの静的デモンストレーションを提供します。既存のsessionsとoutputsデータを使用して、AIエージェント間の対話を閲覧できる静的サイトです。

**Yui Protocol 1.0** と **Yui Protocol 2.0** の両方のデータ形式に対応しています。

## 機能

- 📚 複数のセッションを閲覧
- 🤖 AIエージェント間の対話を表示
- 👥 エージェント詳細情報の表示（名前、役割、性格、思考スタイルなど）
- 🤝 ファシリテーター（コンセンサス構築者）の表示・非表示切り替え
- 📱 レスポンシブデザイン
- 🔍 セッション検索・選択
- 📄 Markdown出力ファイルのプレビュー・ダウンロード
- 📖 読み取り専用モード


## 注意事項

- このサイトは読み取り専用です
- AI実行機能は無効化されています
- セッション作成・編集機能は利用できません
- 静的データのみを表示します
